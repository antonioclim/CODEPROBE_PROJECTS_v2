# Locally generated profiles

This directory is a distribution placeholder, not an approved-profile registry. Keep the corpus, input manifests, per-sample observations and initial calibration outputs in a private workspace outside the kit. Publish a profile here only after a separately recorded institutional decision and a disclosure review.

Follow [the executable workflow](../README.md) for separate file-only and project-only JSON/CSV manifests. The shipped profile template and example are non-operational illustrations. A generated `operational: true` value permits technical replay under the bound engine, mode, configuration and scope; it is not evidence of statistical adequacy or approval.

Keep the reviewed validation summary with the original corpus records. Refit after an engine/configuration identity change rather than editing hashes. Fresh UUID4 observation identifiers vary between exports; source distribution reproducibility is a different contract.
