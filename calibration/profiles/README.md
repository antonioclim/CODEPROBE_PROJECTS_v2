# Local profiles

Store generated course-local profile JSON files here. Recommended naming:

```text
<course>-<language>-<year>-v<revision>.json
```

Examples:

```text
intro-python-2026-v1.json
systems-c-2026-v1.json
web-js-2026-v1.json
```

Do not commit raw student code or identifiable corpus material.
