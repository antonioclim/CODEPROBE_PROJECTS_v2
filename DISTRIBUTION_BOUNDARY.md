# Distribution boundary

## Complete repository snapshot

A tag or GitHub-generated source archive identifies the complete repository snapshot, including the established browser application, project and calibration tools, documentation, tests, release controls and the v2.3.0 evidence-contract integration. It is not equivalent to the bounded article-facing asset.

The repository source is distributed under the existing MIT licence subject to retained notices. The browser configuration can download pinned Pyodide runtime bytes at use time, but no Pyodide runtime distribution is committed in this repository.

## Separately attached bounded source-only asset

`CodeProbe_Source_Only_v2.3.0.zip` is the intended bounded article-facing asset. Its manifest and SHA-256 identify its exact members independently of GitHub's automatically generated complete-repository archives. It contains the admitted evidence-contract source, schemas, research contracts, reader assets, metadata and explicit provenance limits.

## Excluded from both public software assets

- the article manuscript, title page, cover letter, editable figures and editorial files;
- Ruff wheels, Rust crate archives and Radon or Ruff executable/source distributions;
- the exact CE09 qualification package and exact CE11 executable replay package;
- held data/reproducibility candidates, private handover archives, owner returns and internal audits;
- any assertion that software tests establish AI-authorship detection, misconduct detection or population error rates.

CE13-N01 and CE13-N02 are not applicable to the bounded source-only asset because the held third-party executable material is absent. They remain open for the separately preserved CE11 executable replay. The manuscript, figures, data deposit, Zenodo record and DOI retain independent authority and licensing boundaries. A GitHub release does not authorise any of them.
