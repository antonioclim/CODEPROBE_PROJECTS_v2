CodeProbe v2.2.0 — heuristic code and project analysis in the browser

Browser interface for local analysis of Python, JavaScript, Bash, C, C++, C#, Markdown and whole project folders or ZIP archives, including direct drag-and-drop of single files, folders and GitHub-generated ZIP exports. The modular UI exposes JSON/text export, optional local history, lightweight syntax highlighting, .codeprobeignore-aware filtering, manual-review guidance and configurable metric weights and thresholds. The result is a heuristic concern signal and should be read alongside oral examination, version history and assignment context.

Transparent package • browser UI Engine: Python in the browser Project mode • .codeprobeignore aware Engine initialising

Course use policy

The AI-style concern score is a formative review signal, not proof of misconduct. In this course, 60% is a local review trigger rather than a universal validity threshold. Scores above that level should trigger revision, re-analysis and, where required by the module, a brief disclosure.

Default review trigger: 60% Use with Git history and oral explanation
Use on authored code only Check only the files written by the student for the assessed task.
Exclude non-student material Leave out starter code, third-party libraries, generated files, minified assets and documentation.
Use a calibrated trigger when available The bundled 60% trigger is provisional; a course-local calibration profile can replace it.
No automatic penalty Where concern remains, read the report alongside commits, design notes and a short code walkthrough.
Ctrl/Cmd+O opens a file · Ctrl/Cmd+Enter runs analysis · Ctrl/Cmd+S exports JSON
