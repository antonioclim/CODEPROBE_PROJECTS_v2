# Reproducibility boundary

The repository is the source-only research implementation, not the complete executable evidence package.

- **CE09** is the bounded table-reconstruction and native-slice qualification package. It contains the exact retained result and one author-held public-inspection candidate, but no blanket public data licence has been selected.
- **CE11** is the historical replay package. It retains the S05 source, comparator material and the original negative result. It remains private because third-party notice and source-availability obligations are not fully closed for external distribution.
- **CE19 public inspection derivative** exposes selected records without the Ruff wheel or comparator source. Its release remains held until a data licence is chosen.

The two principal denominators remain separate: 1,101 original predicates (1,100 true and one false) and 1,357 defined record comparisons. Do not combine them or convert the failed predicate into a pass.

Use the claim–artefact–command–result matrix in the separate CE19 reproducibility package. A successful local run does not establish universal containment, portability, independent-team reproduction or external validity.
